# Zerion brand-token provenance

The HTML report (`src/scout_portfolio_manager/reporting_html.py`) uses eight colors and one type family from Zerion's published color and typography pages. The inline CSS comments identify the source and Pantone references. The palette first shipped in a browser demo that was removed in 0.7.0.

The repository's contributors created the semantic roles, opacity tints, surfaces, spacing, and radius scale. Those choices are project defaults rather than Zerion design tokens.

This file records source provenance. It does not grant trademark rights or claim Zerion endorsement.
